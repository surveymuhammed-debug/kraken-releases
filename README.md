# kraken-releases
Kraken for Revit - releases and update manifest.

## Install
Download **[Kraken-Setup.exe](https://github.com/surveymuhammed-debug/kraken-releases/raw/main/setup/Kraken-Setup.exe)** and run it.
It finds Revit 2023, 2024, 2025, 2026 (and 2027) on the computer and installs the newest Kraken on each one.
The same link always gives the newest version - nothing to update by hand.

Already installed? Kraken's own **Update** button keeps it current.

Current version: 2.10.1
